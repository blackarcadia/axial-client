# Admin cape

`front.png` preserves the supplied black-and-red cape artwork. `back.png` is a
unique crimson geometric crest reverse generated with the built-in image tool,
using the front as its reference. Both side faces have vertically stacked ADMIN
block lettering spanning almost the full cape height. Ends use crimson trim.

Rebuild with `java -Djava.awt.headless=true tools/GenerateCreatorCape.java admin`.
The sixteen `admin_cape*.png` textures use vanilla cape UVs, a four-second subtle
red shimmer, 320 × 512 main faces, 32 × 512 edges and 320 × 32 ends.

## Reverse generation prompt

Create a flat reverse-side Minecraft cape texture complementary to the supplied front reference. Portrait rectangle aspect ratio 5:8, edge-to-edge black fabric, dark charcoal faceted diagonal pattern. Match the EXACT reference palette of vivid crimson red, blood red, black and very dark charcoal, and crisp pixel clusters. Make this reverse UNIQUE: central angular crimson four-point star enclosed in a broken geometric diamond frame, with two jagged red claw-like ribbons crossing behind it; thinner red diamond accents, tiny red squares and short vertical red drips at the edges echo the front. Strong distinctive admin/rank aesthetic, restrained dark background, readable central emblem. Do not copy the reference's large diagonal slash as the main motif; make a complementary central geometric crest. No skull, NO text, no letters, no gold, no purple, no gradients or blur. Production texture only, NO mockup, no perspective, no folds, no player. Entire portrait flat panel, matching reference Minecraft pixel style.
