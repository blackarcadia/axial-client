# Supplied UI icons

`gear.png` is the user-supplied Mods / Settings gear, prepared as a 128×128 white tintable mask. The original black backdrop was converted to transparency using luminance coverage, preserving the rounded silhouette and soft glow. The artwork is centred in a square with space for the glow.

`tools/generate_mod_ui.py` copies this asset into the client sprite directory so icon regeneration preserves the supplied design.

`quick_waypoints.png` is the supplied Waypoints quick-bar icon, prepared with the same transparency and square framing. It uses a separate sprite so the mod feature retains its original `pin` icon.

`quick_accounts.png` is the supplied Accounts quick-bar icon, prepared with the same transparency and square framing. Other account icons retain their original sprite.

`quick_store.png` is the supplied shopping-cart icon for Store on the quick bar, prepared with the same tintable transparency and square framing.

`quick_forums.png` is the supplied chat-bubble icon for Forums on the quick bar, prepared with the same tintable transparency and square framing.

`move.png` is the supplied four-direction arrow icon for Move HUD / Edit HUD in the menus and quick bar, prepared with the same tintable transparency and square framing.

`sun.png` is the supplied Full Bright icon, prepared with the same tintable transparency and square framing.
