# Gangs menu

Gangs is a full-card menu action in the mod library, with no toggle. It uses the
same settings panel, purple branding, native controls, animation and scrolling
as the other mod menus. Search matches gang names and leader names. Opening a
gang shows its member heads/names/roles, total points, gang-top position and
combined personal balance. Back preserves the directory search and scroll.

Install the updated **PrisonsCore-1.0-SNAPSHOT.jar** along with the updated client.
This API is inside PrisonsCore; no extra plugin is required.

The source is `GangService.topByPoints(Integer.MAX_VALUE)`, preserving the server's
exact gang-top order and tie handling. Points use `getEffectivePoints`. Members
and the leader come from each live Gang. Names are resolved using Bukkit's player
records, with native/default heads while Minecraft skins load asynchronously.
Skin lookups are requested only for visible heads and use a bounded worker queue.

Money is the sum of `EconomyService.getBalance(OfflinePlayer)` for every member,
including offline members. This respects the configured Vault provider as well
as PrisonsCore's internal economy. The gang bank is excluded. If any member's
balance cannot be obtained, the combined figure is marked unavailable.

An open browser requests updates every five seconds. The server shares snapshots
between viewers for five seconds, budgets Bukkit/economy reads across ticks, and
compresses the immutable result off the server thread. Closing the menu stops
polling and ignores late packets. Disconnecting clears the directory and skin
lookup state. A new snapshot replaces the previous one atomically.

The `axial_cosmetics:gangs` channel uses a version-1 nine-byte request (byte 1,
long known revision). Responses use the same bounded fragment envelope as the
enchantment guide: byte 1, long revision, int compressed length, unsigned short
index/count, up to 28,000 gzip bytes. Unchanged snapshots acknowledge with byte 2
and the revision. Limits are 2 MB compressed, 8 MB inflated, 4,096 gangs and 65,536
members total. Each gang carries its ID/name/rank/points, optional leader UUID,
optional decimal combined balance and member UUID/name/role/online records.
The client fixture was generated by PrisonsCore's encoder.
